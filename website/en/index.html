FAQ
A few quick answers.
Is it free?+
Yes. PasteCompiler is open source under the MIT license. Core conversions need no subscription. Any remote AI service you choose may charge separately.
What about Windows, Linux or Intel Macs?+
The ready-to-run download for this release is only for Apple Silicon Macs. Intel Mac, Windows and Linux users can build from source; this release does not include prebuilt packages for those platforms.
Do I need an AI account or API key?+
No. Format detection, core conversions, recipes and built-in natural-language rules work without an AI account. Connecting a model is optional.
Is my data sent to a server?+
Core operations run locally. If you connect a remote AI provider, you control data sample sharing in Settings. The small demo on this page also processes data in your browser.
Is every conversion guaranteed to be lossless?+
No. Some formats cannot represent the same structure. The app parses supported outputs back to report differences and potential loss. SQL, custom templates and plain text do not support this check.
Can I share my recipes?+
Yes. Export recipes as JSON files or short share codes starting with pcr1. and import them on another machine.
